### 面试题

**第 1 题**：`git add` 和 `git commit` 为什么要分成两步？合并成一步不行吗？（提示：想想暂存区存在的意义）

我的回答：add添加到暂存区后如果想修改很方便，提交后修改麻烦
暂存区真正的意义是——让你挑选"这次提交什么"​。

举个真实场景：你今天改了 3 个文件，其中一个改到一半、是个半成品。

有暂存区：你只 add 那两个做完的，半成品留着下次。​半成品不会污染你的提交记录。
假如 add 和 commit 是一步：你只能要么全提交（把半成品也带上），要么全不提交。


**第 2 题**：在 `.gitignore` 里写了 `docs/manual.md` 之后，它就从 `git status` 的列表里消失了。

① 这个文件还在硬盘上吗？
② 如果你以后把 `.gitignore` 里那一行删掉，再跑 `git status`，会发生什么？

我的回答：还在硬盘上，只是git不读取。删掉后就会出现这个文件
